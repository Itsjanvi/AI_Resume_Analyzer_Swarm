# 📝 Swarm AI Resume Analyzer

An AI-powered **Resume Analyzer Web Application** that evaluates resumes against job descriptions using **Swarm Intelligence**, **Natural Language Processing (NLP)**, and **Machine Learning** techniques.

The application helps job seekers understand how well their resume matches a job description by calculating a match score and providing personalized improvement suggestions through an interactive web interface.

---

# 🌐 Web Application

The web application allows users to:

- 📄 Upload their Resume
- 💼 Enter or Upload a Job Description
- 🤖 Analyze Resume Compatibility
- 📊 View Resume Match Score
- 💡 Receive Improvement Suggestions
- ⚡ Get Instant Results

---

# 📌 Project Overview

Recruiters receive hundreds of resumes for every job opening. This project leverages Artificial Intelligence to compare resumes with job descriptions and estimate how well a candidate matches the required skills and qualifications.

The application extracts key information from resumes, compares it with job requirements, and generates a compatibility score along with actionable recommendations to improve the resume.

# ⚙️ How It Works

1. Upload your Resume.
2. Enter or Upload the Job Description.
3. The system extracts important keywords and skills.
4. Swarm Intelligence and NLP compare the resume with the job description.
5. The application generates:
   - Resume Match Score
   - Matching Skills
   - Missing Skills
   - Personalized Suggestions

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/khanzainabshuaib/swarm-ai-resume-analyzer.git
```

Navigate to the project folder

```bash
cd swarm-ai-resume-analyzer
```

Install the required dependencies

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Application

Start the Flask server

```bash
python app.py
```

Open your browser and visit

```
http://127.0.0.1:5000
```

Upload your resume, provide the job description, and click **Analyze Resume**.
